# Demo Prompts

Example prompts you can use to test AutoShop Agent:

## Simple Website

```
Build a personal portfolio website with:
- Home page with hero section
- About page
- Projects showcase
- Contact form
```

## Todo App

```
Create a todo application with:
- Add/remove tasks
- Mark tasks as complete
- Filter by status (all/active/completed)
- Persist data in localStorage
```

## API Dashboard

```
Build a dashboard that displays:
- Real-time API metrics
- Request/response charts
- Error rate monitoring
- Response time graphs
```

## E-commerce Store

```
Create an e-commerce store with:
- Product listing page
- Product detail pages
- Shopping cart
- Checkout flow
```
